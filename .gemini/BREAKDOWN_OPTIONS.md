# Penjelasan Breakdown Dashboard

Saat ini breakdown sudah ada dengan logic:
- Tanpa filter → Breakdown per Seksi
- Filter Seksi → Breakdown per Program
- Filter Program → Breakdown per Kegiatan
- Filter Kegiatan → Breakdown per Sub Kegiatan

## Opsi Implementasi:

### Opsi 1: Tambah 2 Chart Baru (Kegiatan & Sub Kegiatan)
Menampilkan 3 breakdown chart sekaligus:
1. Breakdown per Seksi/Program (existing)
2. Breakdown per Kegiatan (baru)
3. Breakdown per Sub Kegiatan (baru)

### Opsi 2: Tabs untuk Switch Breakdown
Menggunakan tabs untuk switch antara:
- Tab 1: Breakdown per Seksi/Program
- Tab 2: Breakdown per Kegiatan
- Tab 3: Breakdown per Sub Kegiatan

### Opsi 3: Dropdown Selector
User bisa pilih mau lihat breakdown level mana

## Rekomendasi:
Saya sarankan **Opsi 1** - Tambah 2 chart baru karena:
- User bisa lihat semua breakdown sekaligus
- Lebih informatif
- Tidak perlu klik-klik untuk switch view
